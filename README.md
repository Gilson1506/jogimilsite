# JOGIMIL - Tecnologias, Lda.

Site institucional (React + Vite + Tailwind). Paleta: azul-marinho `#050D1A`, azul `#0066FF` e branco.

- `npm run dev` · `npm run build` · `npm run preview`
- Conteúdo editável em `src/data/content.ts` (serviços, portfólio, produtos, notícias, contactos).
- Imagens do portfólio em `public/portfolio/` (WebP, com versão `-480`).
- Os formulários abrem o WhatsApp com a mensagem pronta; guardar dados ou enviar email exige um serviço de backend.
